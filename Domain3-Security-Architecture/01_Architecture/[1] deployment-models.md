
## Architecture Models / Modelos de Arquitectura

Los modelos de arquitectura definen el diseño, la ubicación y el método de despliegue de los activos tecnológicos de una organización. Elegir un modelo de arquitectura depende de aspectos como el nivel de control deseado sobre la infraestructura, la capacidad para gestionar la carga de responsabilidad operativa y las necesidades de seguridad lógica o física de cada activo.

---

## On-Premises
- Control total de infraestructura
- Mayor responsabilidad operativa
- Dependencia de controles físicos y de red

## Cloud
- Modelo de responsabilidad compartida
- Enfoque en IAM, cifrado y configuración segura
- Riesgo de mala configuración

## Virtualización
- Aislamiento lógico
- Riesgos de escape de VM
- Importancia del hardening del hipervisor

## IoT
- Recursos limitados
- Alta superficie de ataque
- Necesidad de segmentación estricta

## ICS
- Prioridad en disponibilidad
- Protocolos legacy
- Seguridad perimetral crítica

## Infrastructure as Code (IaC)
- Configuración reproducible
- Riesgo de errores automatizados
- Necesidad de control de versiones y revisión
