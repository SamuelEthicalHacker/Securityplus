## Domain 2 - Security Architecture (CompTIA Security+)

Este módulo contiene documentación técnica y laboratorios prácticos alineados con el Dominio 2: Arquitectura de Seguridad.

🔴 Objetivo del Dominio

Aplicar principios de seguridad al diseño de arquitecturas empresariales, cubriendo infraestructura, protección de datos y resiliencia operativa.

🔴 Contenido del Dominio

• Modelos de arquitectura: on-premises, cloud, virtualización, IoT, ICS, IaC  
• Infraestructura empresarial segura y segmentación  
• Protección y clasificación de datos  
• Alta disponibilidad y continuidad del negocio  

🔴 Laboratorios

1. Segmentación de infraestructura empresarial (LAN / DMZ)  
2. Protección y clasificación de datos  

Cada laboratorio incluye evidencia técnica y documentación alineada 100% al Security+.
