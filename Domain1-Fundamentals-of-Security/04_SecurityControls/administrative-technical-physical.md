# Administrative / Technical / Physical Controls

**Categorías de controles:**

1. **Administrative (Directivos)**  
   - Definen políticas, procedimientos y roles.  
   - Ejemplos: políticas de seguridad, capacitación, procedimientos de respuesta a incidentes, evaluaciones de riesgo.

2. **Technical (Técnicos)**  
   - Implementados por tecnología para proteger sistemas.  
   - Ejemplos: firewalls, EDR, cifrado, autenticación multifactor, control de acceso lógico.

3. **Physical (Físicos)**  
   - Protegen el acceso físico a activos.  
   - Ejemplos: cerraduras, control de acceso con tarjetas, CCTV, sensores ambientales, UPS.

**Relación práctica:**  
- Una política (administrativa) puede requerir MFA; MFA se implementa técnicamente; y las credenciales de hardware se guardan físicamente.

**Good practice:** documentar cada control con responsable, métricas de efectividad y cadencia de revisión.
