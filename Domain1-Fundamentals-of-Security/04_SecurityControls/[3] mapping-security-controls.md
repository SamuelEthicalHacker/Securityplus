# Mapping Security Controls

**Objetivo de este documento:** mostrar un mapeo de controles a objetivos (CIA) y tipo de control.

Tabla ejemplo (resumen):

| Objetivo CIA | Ejemplo control | Tipo (Admin/Tech/Phys) | Preventive/Detective/Corrective |
|--------------|------------------|------------------------:|-------------------------------:|
| Confidentiality | AES encryption at rest | Technical | Preventive |
| Integrity | File Integrity Monitoring | Technical | Detective |
| Availability | Offsite backups | Administrative/Technical | Corrective |
| Confidentiality | Data classification policy | Administrative | Preventive |
| Availability | Redundant power / UPS | Physical/Technical | Preventive/Corrective |

**Cómo usar:** para cada activo crítico, mapear controles existentes y detectar brechas (gap analysis).
