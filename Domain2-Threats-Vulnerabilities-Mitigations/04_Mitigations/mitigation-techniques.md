
# Mitigation Techniques / Técnicas de mitigación

Las técnicas de mitigación reducen la probabilidad y el impacto de amenazas explotando vulnerabilidades conocidas. En Security+ el enfoque está en **prevención, reducción de superficie de ataque y contención**.


## Segmentation / Segmentación
- Divide la red en zonas lógicas o físicas
- Limita el movimiento lateral de un atacante
- Reduce el impacto de una brecha de seguridad
- Se implementa mediante VLANs, firewalls internos o zonas de seguridad

## Access Control / Control de acceso
- Aplica el principio de mínimo privilegio
- Restringe el acceso solo a usuarios y sistemas autorizados
- Uso de autenticación multifactor (MFA)
- Reduce riesgos por credenciales comprometidas


## Configuration Enforcement / Aplicación de configuraciones seguras
- Uso de baselines de seguridad
- Configuraciones estandarizadas y documentadas
- Previene desviaciones inseguras en sistemas
- Facilita auditorías y cumplimiento

## Hardening / Endurecimiento de sistemas
- Eliminación de servicios, puertos y cuentas innecesarias
- Desactivación de funciones no utilizadas
- Reducción de la superficie de ataque
- Aumenta la resistencia ante ataques automatizados

## Isolation / Aislamiento
- Separación de sistemas críticos
- Contención de sistemas comprometidos
- Uso de entornos aislados o sandbox
- Evita la propagación del ataque

## Patching / Gestión de parches
- Corrección de vulnerabilidades conocidas
- Reducción de exploits basados en fallos públicos
- Aplicación oportuna de actualizaciones
- Elemento clave en la gestión de vulnerabilidades


**Enfoque Security+**

🔵❗ Las mitigaciones no eliminan amenazas, **reducen el riesgo** mediante controles técnicos y operativos aplicados de forma estratégica.
