# Reporte Técnico – Dominio 5

En este reporte mi enfoque es demostrar cómo un programa de seguridad organiza, supervisa y gestiona la seguridad de la información dentro de una organización.

Este dominio se centra en los componentes estratégicos necesarios para:

- Establecer estructuras de gobernanza de seguridad
- Gestionar riesgos organizacionales
- Evaluar riesgos de terceros
- Asegurar cumplimiento regulatorio
- Validar controles mediante auditorías y evaluaciones

A diferencia de los dominios operativos, este dominio aborda cómo la seguridad se gestiona a nivel organizacional para garantizar una supervisión efectiva y una toma de decisiones basada en riesgo.


## Key Components / Componentes Clave

1. Security Governance / Gobernanza de Seguridad  
2. Enterprise Risk Management / Gestión de Riesgos Empresariales  
3. Third-Party Risk Management / Gestión de Riesgo de Terceros  
4. Security Compliance / Cumplimiento de Seguridad  
5. Security Audits and Assessments / Auditorías y Evaluaciones de Seguridad  


## Security Governance Model / Modelo de Gobernanza de Seguridad

1. Definir → Políticas, estándares y responsabilidades de seguridad  
2. Evaluar → Identificación y análisis de riesgos organizacionales  
3. Controlar → Implementación de controles de seguridad y cumplimiento  
4. Supervisar → Auditorías, monitoreo y revisiones del programa de seguridad  

El enfoque es estratégico y orientado a la gestión continua del riesgo dentro de la organización.
