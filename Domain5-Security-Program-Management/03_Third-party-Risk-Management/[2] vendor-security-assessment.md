# Vendor Security Assessment / Evaluación de Seguridad de Proveedores

La Evaluación de Seguridad de Proveedores es un proceso utilizado para evaluar los controles de seguridad implementados por un proveedor 
antes de permitirle acceso a sistemas, datos o infraestructura de la organización.

Este proceso permite identificar posibles debilidades de seguridad que podrían introducir riesgos para la organización.

## Security Questionnaires / Cuestionarios de Seguridad

Uno de los métodos más comunes para evaluar proveedores es mediante cuestionarios de seguridad.

Estos cuestionarios solicitan información sobre los controles implementados por el proveedor, tales como:

- control de acceso
- cifrado de datos
- gestión de incidentes
- monitoreo de seguridad

Las respuestas permiten evaluar el nivel de madurez de seguridad del proveedor.

## Security Control Evaluation / Evaluación de Controles de Seguridad

Además de los cuestionarios, las organizaciones pueden evaluar directamente los controles de seguridad del proveedor.

Esto puede incluir:

- revisión de políticas de seguridad
- análisis de configuraciones de seguridad
- revisión de reportes de auditoría

El objetivo es verificar que el proveedor cumpla con los estándares de seguridad requeridos.

## Risk Classification / Clasificación de Riesgo

Una vez evaluados los controles del proveedor, se asigna un nivel de riesgo basado en factores como:

- sensibilidad de los datos manejados
- nivel de acceso a los sistemas
- dependencia operativa del proveedor

Esta clasificación permite priorizar las medidas de seguridad necesarias para cada proveedor.
