# Vendor Security Agreements and SLA / Acuerdos de Seguridad y SLA con Proveedores

Los acuerdos de seguridad con proveedores establecen los requisitos que un proveedor debe cumplir para proteger los sistemas y datos de la organización.

Estos acuerdos suelen incluir cláusulas de seguridad dentro de contratos o acuerdos de nivel de servicio.

## Service Level Agreement (SLA) / Acuerdo de Nivel de Servicio

Un SLA define los niveles de servicio que un proveedor debe cumplir durante la prestación de sus servicios.

Los SLA pueden incluir requisitos relacionados con:

- disponibilidad del servicio
- tiempos de respuesta ante incidentes
- soporte técnico

Estos acuerdos ayudan a garantizar que el proveedor cumpla con expectativas operativas y de seguridad.

## Security Requirements / Requisitos de Seguridad

Los contratos con proveedores suelen incluir requisitos de seguridad específicos, tales como:

- implementación de controles de acceso
- protección de datos sensibles
- cifrado de información

Estos requisitos ayudan a reducir los riesgos asociados con el acceso de terceros.

## Breach Notification / Notificación de Incidentes

Los acuerdos también pueden incluir requisitos para que el proveedor notifique a la organización en caso de incidentes de seguridad.

Esto permite que la organización pueda responder rápidamente ante posibles compromisos de seguridad.
