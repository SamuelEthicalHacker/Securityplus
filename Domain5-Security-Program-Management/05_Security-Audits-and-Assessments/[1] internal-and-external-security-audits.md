# Internal and External Security Audits / Auditorías de Seguridad Internas y Externas

Las auditorías de seguridad permiten evaluar si los controles implementados por una organización cumplen con políticas internas y requisitos regulatorios.

Estas auditorías ayudan a identificar debilidades de seguridad y mejorar continuamente el programa de seguridad.

## Internal Audits / Auditorías Internas

Las auditorías internas son realizadas por equipos internos de la organización.

Su objetivo es verificar que los controles de seguridad se implementen correctamente y que las políticas organizacionales se cumplan.

Estas auditorías permiten identificar problemas antes de que sean detectados por entidades externas.

## External Audits / Auditorías Externas

Las auditorías externas son realizadas por auditores independientes o entidades regulatorias.

Su objetivo es validar que la organización cumple con estándares de seguridad y requisitos regulatorios.

Estas auditorías proporcionan una evaluación objetiva del programa de seguridad.

## Audit Evidence / Evidencia de Auditoría

Durante una auditoría se recopila evidencia para demostrar que los controles de seguridad están funcionando correctamente.

Esta evidencia puede incluir:

- registros de auditoría
- configuraciones de seguridad
- documentación de políticas

## Reflexión Técnica

Estudiar esta sección me encantó, las auditorias tanto internas como externas son de mis procesos favoritos en la seguridad de la información.
Comprendí que estas evaluaciones permiten validar la efectividad de los controles de seguridad implementados en una organización.

Durante este análisis pude darme cuenta de un factor clave: las auditorías internas ayudan a identificar debilidades antes de que se conviertan en problemas mayores, 
mientras que las auditorías externas proporcionan una evaluación independiente del programa de seguridad.
