# Business Impact Analysis (BIA) / Análisis de Impacto al Negocio

El Business Impact Analysis permite evaluar cómo la interrupción de sistemas o procesos críticos podría afectar las operaciones de una organización.

Este análisis es fundamental para la planificación de continuidad del negocio y recuperación ante desastres.

## Critical Business Processes / Procesos Críticos

El primer paso del BIA consiste en identificar los procesos de negocio más importantes para la organización.

Estos procesos suelen depender de sistemas tecnológicos y recursos específicos.

## Impact Analysis / Análisis de Impacto

Durante esta fase se evalúan las consecuencias que tendría la interrupción de un sistema o proceso crítico.

El impacto puede incluir:

- pérdida financiera
- interrupción de servicios
- daño reputacional

## Recovery Objectives / Objetivos de Recuperación

El BIA también permite definir objetivos clave de recuperación.

Recovery Time Objective (RTO) / Tiempo Objetivo de Recuperación  
Tiempo máximo permitido para restaurar un sistema después de una interrupción.

Recovery Point Objective (RPO) / Punto Objetivo de Recuperación  
Cantidad máxima de datos que la organización puede permitirse perder.

Maximum Tolerable Downtime (MTD) / Tiempo Máximo Tolerable de Interrupción  
Tiempo máximo que un proceso puede estar fuera de servicio antes de causar daño crítico al negocio.

Estos objetivos ayudan a definir estrategias de recuperación y continuidad operativa.
