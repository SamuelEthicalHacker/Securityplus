# Security Program Management and Oversight / Gestión y Supervisión del Programa de Seguridad

Este dominio aborda los componentes estratégicos necesarios para gestionar un programa de seguridad dentro de una organización.
A diferencia de los dominios técnicos enfocados en operaciones de seguridad, este dominio se centra en la gobernanza, gestión de riesgos,
cumplimiento normativo y supervisión de controles de seguridad.


🔴 Objetivo del Dominio

Mi objetivo en este espacio es documentar la manera en cómo las organizaciones establecen estructuras formales de seguridad para 
garantizar que los riesgos sean identificados, evaluados y tratados de manera sistemática, todo alineado al Security+.


🔵 Structure / Estructura

- Security Governance / Gobernanza de Seguridad  
Define la estructura organizacional, responsabilidades y mecanismos de supervisión que permiten dirigir el programa de seguridad.

- Enterprise Risk Management / Gestión de Riesgos Empresariales  
Permite identificar, analizar y tratar riesgos que puedan afectar los activos, procesos y operaciones de la organización.

- Security Compliance / Cumplimiento de Seguridad  
Asegura que los controles de seguridad se alineen con requisitos regulatorios, legales y organizacionales.

- Security Audits and Assessments / Auditorías y Evaluaciones de Seguridad  
Permiten validar que los controles de seguridad funcionen correctamente y que las políticas sean aplicadas de forma consistente.

- Security Awareness / Concienciación en Seguridad  
Busca fortalecer el comportamiento seguro de los usuarios mediante capacitación y monitoreo de actividades sospechosas.


🔵 Laboratorios

1. **Risk Assessment and Business Impact Analysis (BIA)**  
   Evaluación estructurada de riesgos organizacionales mediante identificación, análisis de probabilidad e impacto, y priorización utilizando matrices de riesgo. Incluye la elaboración de un Business Impact Analysis para determinar procesos críticos y definir objetivos de recuperación como RTO, RPO y MTD.

2. **Vendor Risk Evaluation**  
   Análisis del riesgo asociado a terceros mediante la evaluación de controles de seguridad de proveedores, revisión de cuestionarios de seguridad y priorización del riesgo basado en la criticidad del servicio y la sensibilidad de los datos gestionados por el proveedor.

3. **Security Compliance Audit**  
   Revisión de controles de seguridad mediante un proceso de auditoría estructurado, incluyendo validación de cumplimiento, recopilación de evidencia y análisis de hallazgos. El laboratorio también contempla la documentación del proceso de auditoría y el seguimiento de acciones de remediación.
