# Reflexión Técnica

Durante este mini-laboratorio analicé cómo las organizaciones pueden evaluar el nivel de cumplimiento de sus controles de seguridad
a través de auditorías internas y herramientas de visualización como paneles de cumplimiento.

## Security Compliance Dashboard

Como parte del laboratorio elaboré un panel de control de cumplimiento de seguridad que representa el estado de diferentes dominios clave dentro
de una organización ficticia. En este panel se evaluaron áreas fundamentales como el control de acceso, la protección de datos, la seguridad de red, 
la respuesta a incidentes y la gobernanza de seguridad, aspectos de suma importancia en auditorias.

A través de este ejercicio he podido comprender más sobre cómo las organizaciones pueden representar visualmente el estado de sus controles de seguridad
para obtener una visión clara de su postura de cumplimiento.

## Evaluación de Controles de Seguridad

Durante el análisis del panel también pude observar cómo cada dominio de seguridad puede presentar distintos niveles de cumplimiento.
Por ejemplo, algunas áreas como la gobernanza de seguridad muestran un nivel alto de cumplimiento, mientras que otras, como la respuesta a incidentes, 
presentan un nivel menor que podría indicar la necesidad de mejorar procedimientos o controles asociados.

Este tipo de evaluación permite a las organizaciones identificar rápidamente qué áreas requieren mayor atención o inversión en controles de seguridad.

## Importancia de las Auditorías de Seguridad

Finalmente, este laboratorio me permitió comprender mejor el papel de las auditorías dentro de los programas de seguridad organizacional. 

Me quedo más que claro el hecho de que las auditorías permiten verificar si los controles definidos en políticas o estándares realmente 
se encuentran implementados y funcionando correctamente.
