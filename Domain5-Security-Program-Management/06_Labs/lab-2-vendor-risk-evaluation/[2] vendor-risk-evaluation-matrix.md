# Vendor Risk Evaluation Matrix / Matriz de Evaluación de Riesgo de Proveedores

La evaluación de riesgos de proveedores permite analizar los riesgos asociados con terceros que pueden tener acceso a sistemas, 
infraestructura o información sensible de una organización.

Este proceso forma parte del **Third-Party Risk Management**, cuyo objetivo es identificar, evaluar y gestionar los riesgos que 
pueden introducir los proveedores externos.

## Evaluation Criteria / Criterios de Evaluación

Para evaluar el riesgo de un proveedor se analizan diferentes factores relacionados con el acceso que tendrá al entorno organizacional
y con la madurez de sus controles de seguridad.

Los criterios más comunes incluyen:

- sensibilidad de los datos
- nivel de acceso a sistemas internos
- controles de seguridad implementados
- cumplimiento de normativas o estándares de seguridad

Estos factores permiten determinar el nivel de riesgo asociado con cada proveedor.

## Vendor Risk Evaluation Matrix / Matriz de Evaluación de Riesgo de Proveedores

A continuación presento una matriz que ejemplifica cómo las organizaciones evalúan el riesgo asociado con proveedores externos.

| Vendor / Proveedor | Data Sensitivity / Sensibilidad de Datos | System Access / Acceso a Sistemas | Security Controls / Controles de Seguridad | Compliance Status / Cumplimiento | Risk Level / Nivel de Riesgo |
|---|---|---|---|---|---|
| Cloud Storage Provider | Alta exposición a datos sensibles de clientes | Acceso a infraestructura de almacenamiento | Controles de seguridad parcialmente documentados | Cumplimiento parcial de estándares | Alto |
| Marketing Platform | Acceso limitado a información de clientes | Acceso a sistemas externos integrados | Controles de seguridad básicos | Cumplimiento moderado | Medio |
| IT Support Vendor | Acceso privilegiado a sistemas internos | Acceso administrativo a servidores | Controles de seguridad avanzados | Cumplimiento de estándares reconocidos | Medio |

## Risk Classification / Clasificación del Riesgo

Los proveedores pueden clasificarse según el nivel de riesgo que representan para la organización.

- **High Risk / Riesgo Alto**  
  Proveedores con acceso a información crítica o sistemas sensibles.

- **Medium Risk / Riesgo Medio**  
  Proveedores con acceso limitado o controles de seguridad adecuados.

- **Low Risk / Riesgo Bajo**  
  Proveedores con acceso mínimo a sistemas o datos.

Esta clasificación permite priorizar la implementación de controles adicionales y la supervisión de los proveedores con mayor riesgo.

La evaluación de proveedores permite reducir riesgos asociados con terceros y fortalecer la postura de seguridad de la organización.
