# Reflexión Técnica

Durante este mini-laboratorio analicé el proceso de evaluación de riesgos asociados con proveedores externos.

## Vendor Risk Assessment

En primer lugar, un aspecto que me resultó especialmente interesante fue el uso de cuestionarios de seguridad. Mediante esta herramienta de evaluación, las organizaciones pueden recopilar información relevante sobre los controles de seguridad implementados por un proveedor.

Comprendí que este tipo de evaluación permite identificar posibles debilidades antes de establecer una relación contractual.

También entendí que este proceso forma parte fundamental de la gestión de riesgos de terceros.

## Risk Evaluation

Durante el análisis de la matriz de evaluación de proveedores observé que esta herramienta permite analizar diferentes factores de riesgo, como el acceso a sistemas, la sensibilidad de los datos y los controles de seguridad implementados.

A través de este análisis pude clasificar a los proveedores según su nivel de riesgo y comprender cómo definir controles adicionales cuando sea necesario.

Finalmente, este laboratorio reforzó mi comprensión sobre la importancia de evaluar los riesgos asociados con terceros antes de permitirles acceso a sistemas o información sensible.

La evaluación de proveedores es una práctica fundamental para reducir riesgos dentro de un programa de seguridad organizacional.
