# Policies, Standards and Procedures / Políticas, Estándares y Procedimientos

Las políticas, estándares y procedimientos son documentos fundamentales dentro de un programa de seguridad. 
Estos documentos establecen las reglas y directrices que deben seguir los usuarios y los equipos técnicos dentro de la organización.

## Security Policy / Política de Seguridad

Una política de seguridad define la dirección estratégica y los principios generales que guían la seguridad de la información dentro de la organización.

Las políticas suelen establecer:

- objetivos de seguridad
- responsabilidades generales
- requisitos de cumplimiento

Las políticas son documentos de alto nivel aprobados por la dirección.

## Security Standards / Estándares de Seguridad

Los estándares definen requisitos técnicos específicos que deben cumplirse para garantizar la seguridad de los sistemas y procesos.

Ejemplos de estándares incluyen:

- requisitos mínimos de configuración segura
- estándares de cifrado
- políticas de control de acceso

Los estándares garantizan que las políticas sean aplicadas de forma consistente.

## Security Procedures / Procedimientos de Seguridad

Los procedimientos describen los pasos específicos que deben seguirse para implementar o ejecutar un control de seguridad.

Ejemplos de procedimientos incluyen:

- proceso de gestión de incidentes
- proceso de gestión de vulnerabilidades
- procedimiento de respaldo y recuperación de datos

Los procedimientos permiten que las políticas y estándares sean aplicados de forma práctica dentro de la organización.

## Reflexión Técnica

Con esta sección he complementado un aspecto importante: la diferenciación entre políticas, estándares y procedimientos es fundamental dentro de un programa de seguridad maduro.

Durante este análisis comprendí que las políticas establecen la dirección estratégica, los estándares definen los requisitos técnicos obligatorios y
los procedimientos proporcionan las instrucciones operativas necesarias para aplicar los controles de seguridad.

Me he dado cuenta de que esta estructura jerárquica permite que las organizaciones implementen controles de seguridad de manera consistente, 
asegurando que las decisiones estratégicas puedan traducirse en prácticas operativas concretas dentro de los equipos técnicos.
