# Security Governance Framework / Marco de Gobernanza de Seguridad

La gobernanza de seguridad establece la estructura organizacional que permite dirigir y supervisar el programa de seguridad dentro de una organización.

Su objetivo principal es garantizar que las decisiones relacionadas con seguridad estén alineadas con los objetivos estratégicos del negocio.

## Governance Structure / Estructura de Gobernanza

La estructura de gobernanza define los roles, responsabilidades y niveles de autoridad dentro del programa de seguridad.

Esta estructura suele incluir:

- Chief Information Security Officer (CISO)  
Responsable de dirigir la estrategia de seguridad de la organización.

- Security Steering Committee / Comité de Seguridad  
Grupo encargado de supervisar decisiones estratégicas relacionadas con seguridad.

- Security Operations Team / Equipo de Operaciones de Seguridad  
Encargado de implementar y operar los controles de seguridad.

## Security Oversight / Supervisión de Seguridad

La supervisión permite evaluar si las políticas y controles de seguridad están siendo aplicados correctamente dentro de la organización.

Esto incluye actividades como:

- revisión de controles de seguridad
- evaluación de riesgos
- monitoreo de cumplimiento

## Governance Objectives / Objetivos de la Gobernanza

Los principales objetivos de la gobernanza de seguridad son:

- establecer una dirección clara para el programa de seguridad  
- garantizar responsabilidad en la gestión de seguridad  
- supervisar la implementación de controles de seguridad  
- asegurar alineación entre seguridad y objetivos del negocio

## Reflexión Técnica

Durante el análisis del marco de gobernanza de seguridad he reforzado un concepto fundamental: la seguridad organizacional no depende únicamente de controles técnicos,
sino de una estructura clara de liderazgo, supervisión y responsabilidad.

Un marco de gobernanza efectivo permite que las decisiones de seguridad se alineen con los objetivos del negocio, 
estableciendo mecanismos formales de supervisión y rendición de cuentas.

Con esta sección he podido reforzar otro aspecto clave: la seguridad debe ser gestionada como una función estratégica dentro de la organización,
donde roles como el CISO, los comités de seguridad y los equipos operativos colaboran para garantizar una gestión consistente del riesgo.
