
# Reporte Técnico – Dominio 4

En este reporte mi enfoque es demostrar una implementación práctica de controles de seguridad para:

- Reducir superficie de ataque
- Detectar actividades maliciosas
- Gestionar vulnerabilidades
- Responder a incidentes

Este dominio conecta la teoría de seguridad con la operación diaria en entornos empresariales.


## Key Components / Componentes Clave

1. Secure Baselines y Hardening
2. Asset & Vulnerability Management
3. Continuous Monitoring
4. Identity and Access Control
5. Incident Response Lifecycle

## Operational Security Model / Modelo Operativo

1. Prevenir → Hardening y control de acceso
2. Detectar → Monitoreo y alertas
3. Responder → Contención y erradicación
4. Mejorar → Lessons learned y ajustes

El enfoque es continuo y basado en riesgo.
