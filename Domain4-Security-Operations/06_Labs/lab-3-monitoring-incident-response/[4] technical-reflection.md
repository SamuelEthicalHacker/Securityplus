# Reflexión Técnica

## Monitoring and Incident Response / Monitoreo y Respuesta a Incidentes

Durante este mini-laboratorio analicé cómo las organizaciones implementan procesos de **monitoreo de seguridad continuo** para 
detectar actividades sospechosas dentro de sus entornos tecnológicos.

Algo que realmente me encantó fue ver la manera en la que el flujo de monitoreo conecta diferentes fuentes de eventos, como registros del sistema, 
dispositivos de red y aplicaciones, con plataformas de análisis centralizadas como los **SIEM**, donde los eventos pueden ser correlacionados
para identificar posibles incidentes de seguridad.

También comprendí el papel de los analistas dentro de un **Security Operations Center (SOC)**, quienes realizan procesos de análisis inicial
y clasificación de alertas antes de determinar si una actividad representa un incidente de seguridad. Esto me pareció sumamente interesante ya que 
con este concepto puedo tener una idea clara de cuando hay un falso positivo y cuando existe un incidente legítimo.

Asimismo, analicé el proceso estructurado de **respuesta a incidentes**, el cual incluye fases como identificación, contención, erradicación, 
recuperación y análisis posterior al incidente.

Este ejercicio reforzó mi comprensión sobre la importancia de contar con **procesos definidos de detección y respuesta**, permitiendo a 
las organizaciones reaccionar de manera efectiva ante eventos de seguridad y minimizar su impacto operativo.
