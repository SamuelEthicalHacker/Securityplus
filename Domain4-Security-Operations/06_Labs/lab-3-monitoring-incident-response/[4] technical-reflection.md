# Reflexión Técnica

## Monitoring and Incident Response / Monitoreo y Respuesta a Incidentes

Durante este mini-laboratorio he analizado cómo las organizaciones implementan procesos de monitoreo de seguridad continuo para detectar actividades sospechosas dentro de sus entornos tecnológicos.

Uno de los aspectos que más me llamó la atención fue observar cómo el flujo de monitoreo conecta diferentes fuentes de eventos, como registros del sistema, dispositivos de red y aplicaciones, con plataformas de análisis centralizadas como los SIEM, donde los eventos pueden ser correlacionados para identificar posibles incidentes de seguridad.

También he comprendido el papel de los analistas dentro de un Security Operations Center (SOC), quienes realizan procesos de análisis inicial y clasificación de alertas antes de determinar si una actividad representa un incidente de seguridad. Este concepto me ha permitido comprender mejor cómo diferenciar entre falsos positivos y eventos que pueden representar incidentes legítimos.

Asimismo, he analizado el proceso estructurado de respuesta a incidentes, el cual incluye fases como identificación, contención, erradicación, recuperación y análisis posterior al incidente.

Finalmente, este ejercicio ha reforzado mi comprensión sobre la importancia de contar con procesos definidos de detección y respuesta, permitiendo a las organizaciones reaccionar de manera efectiva ante eventos de seguridad y minimizar su impacto operativo.
