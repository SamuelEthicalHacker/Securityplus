# System Hardening & Security Baseline / Endurecimiento del Sistema y Línea Base de Seguridad

## Objetivo

Mi objetivo con este minilab es diseñar un modelo conceptual de línea base de seguridad que permita reducir
la superficie de ataque de un sistema, aplicando principios fundamentales de seguridad defensiva.

---

## Enfoque del Laboratorio

Este laboratorio se centra en la construcción estructurada de un modelo de endurecimiento aplicable a cualquier entorno.

Se desarrolla:

- Modelo de defensa en profundidad
- Clasificación de controles
- Identificación de superficie de ataque
- Matriz de priorización de controles

## Principios Aplicados

- Defensa en Profundidad
- Principio de Mínimo Privilegio
- Reducción de Superficie de Ataque
- Separación de Controles Preventivos, Detectivos y Correctivos


## Resultado

Se obtiene una estructura visual y estratégica que puede servir como plantilla base para implementar
hardening en cualquier sistema operativo o entorno empresarial.
