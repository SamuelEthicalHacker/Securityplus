# Security Baseline Matrix / Matriz Conceptual de Línea Base de Seguridad

| Capa de Seguridad | Tipo de Control | Objetivo | Nivel de Impacto | Prioridad |
|-------------------|----------------|----------|------------------|-----------|
| Políticas de Autenticación | Preventivo | Reducir acceso no autorizado | Alto | Alta |
| Gestión de Servicios | Preventivo | Disminuir superficie de ataque | Alto | Alta |
| Configuración de Red | Preventivo | Limitar exposición | Alto | Alta |
| Auditoría y Logs | Detectivo | Identificar actividad sospechosa | Medio | Media |
| Respuesta a Incidentes | Correctivo | Contener amenazas | Alto | Alta |

---

## Lógica de Construcción de la Baseline

He diseñado la línea base siguiendo un orden claro:

1. Identificación de activos críticos.
2. Evaluación de posibles vectores de ataque.
3. Aplicación de controles en capas.
4. Priorización según impacto potencial.


## Observación Estratégica

Una baseline no es una lista de configuraciones, sino una arquitectura defensiva estructurada.
