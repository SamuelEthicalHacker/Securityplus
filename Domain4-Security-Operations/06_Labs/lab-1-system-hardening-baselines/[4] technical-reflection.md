# Reflexión Técnica

## System Hardening Baselines / Endurecimiento de Sistemas

Durante este mini-laboratorio pude comprender la importancia de establecer configuraciones base seguras (security baselines) para fortalecer la seguridad de los sistemas operativos.

Evalué cómo el proceso de system hardening permite reducir la superficie de ataque mediante la aplicación de configuraciones seguras, la restricción de servicios innecesarios y el control de parámetros críticos del sistema.

Esta práctica me sirvió como complemento, ya que reforcé un aspecto clave: el hardening no consiste únicamente en aplicar configuraciones aisladas, sino en definir un estado de seguridad estandarizado y verificable que pueda mantenerse de forma consistente dentro de una organización.

Este ejercicio reforzó mi comprensión sobre cómo los security baselines funcionan como una medida preventiva clave, permitiendo disminuir vectores de ataque comunes antes de que puedan ser explotados por un actor malicioso.

Asimismo, comprendí que mantener configuraciones seguras facilita los procesos de auditoría de seguridad y control de cumplimiento, ya que permite detectar desviaciones respecto a la configuración esperada del sistema.
