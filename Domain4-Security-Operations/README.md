
## Domain 4 - Security Operations 

Este dominio aborda los procesos y controles necesarios para mantener la seguridad operativa de una organización. 

Se enfoca en:

- Hardening y secure baselines
- Gestión de activos y vulnerabilidades
- Monitoreo y detección
- Gestión de identidad
- Respuesta a incidentes
- Automatización y orquestación

🔴 Objetivo del Dominio

El objetivo es comprender cómo se protege, supervisa y responde ante amenazas en un entorno empresarial real.



🔵 Structure / Estructura

- Computing Resources
- Asset and Vulnerability Management
- Monitoring and Detection
- Identity and Automation
- Incident Response



🔵 Laboratorios

1. **System Hardening and Baselines**  
   Análisis y aplicación de configuraciones seguras (secure baselines), reducción de superficie de ataque y endurecimiento de servicios en sistemas empresariales.

2. **Vulnerability Management Cycle**  
   Evaluación del ciclo completo de gestión de vulnerabilidades: identificación, priorización basada en riesgo y planificación de remediación dentro de un entorno operativo.

3. **Monitoring and Incident Response**  
   Análisis de alertas, construcción de línea de tiempo del incidente y ejecución de acciones de respuesta, incluyendo documentación técnica y lecciones aprendidas.


Con cada laboratorio mi enfoque es demostrar evidencia técnica clara y documentación concisa, centrada en análisis práctico, procesos operativos reales y alineada con los objetivos evaluados por Security+.
